主干 — 五步走，时间轴归程序

01 / ASR

MAI-Transcribe-2

词级时间戳 + speaker 分离，长音频自动切片、逐块缓存重试。

02 / ATOMS

确定性拆分

按静音、标点、speaker 边界切原子——LLM 不参与，时间戳永远精确。

03 / MERGE

Gemini 断句

只合并 atom，不生成时间轴；结果按内容哈希缓存，断点续跑。

04 / TRANSLATE

Gemini 翻译

JSON 契约输出、按 id 对齐，缺行自动二分重试。

05 / SRT

程序渲染

译文映射回原始时间轴输出 SRT——LLM 从头到尾碰不到时间戳。

可选支线 — 没有词库，也能全片译名一致

完整链路--extract-frames → 代表帧 → 外部 OCR → Jev 筛掉效果字/对白 → 纯文本 pre-pass
无 JEV--ocr-json 直进 pre-pass——没有 Cloudflare / TypeSafe 凭据也能跑
无 OCR--prepass 只用字幕全文生成词库
远程来源BV / ep / Abema / YouTube ID 或 URL → yt-dlp 下载；TVer/Abema cast 名单作为权威人名锚点直进 pre-pass
产物glossary.md 自动词库（原文 → 写法），注入每一个翻译批次
